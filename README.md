# おつかいメモ

買い物メモを覚えて、お店の棚から選び、お会計を計算し、最後にもう一度思い出す。1日3回のおつかいで、頭を使う習慣づくりをするゲームです。

- 遊ぶ: https://satou-aaaaa.github.io/otsukai-memo/
- 今日のおつかい（3品・4品・5品と、最後の思い出し）はだれでも同じで1日1回。上級（6品・7品、お会計はおつり）、練習（3〜8品・何回でも）、とことん（一度で覚えるたびにメモが1品ふえる）があります。
- 時間制限はありません。大きな文字とボタンで、文字の大きさは3段から選べます。
- 毎日「覚え方のコツ」（仲間で分ける・お話にする・声に出す など）を1つ出します。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（品物の名前は入りません）。

## 研究で分かっていること（言い切らないために）

- WHO の指針（2019）は、認知機能が正常な人・軽い低下のある人に、頭の訓練を「勧めてもよい」（条件付き）としています。根拠の確かさは「とても低い〜低い」です。[WHO guidelines 2019](https://www.who.int/publications/i/item/9789241550543)
- 認知症の危険を下げると考えられているのは、運動・血圧・禁煙・聞こえ・人との交流など14の要因への手当てです。[Lancet 委員会 2024](https://doi.org/10.1016/S0140-6736(24)01296-0)
- 健康な高齢者へのパソコンでの頭の訓練は、全体として小さな効果（g＝0.22）。一人で家でやるより人といっしょのほうが効果が見え、週3回より多くしても上乗せは見られなかった。[Lampit ほか 2014](https://doi.org/10.1371/journal.pmed.1001756)
- 覚え方のコツ（記憶の方略）を教える練習は、ACTIVE 試験で記憶の練習として使われた方法です。[Rebok ほか 2014](https://doi.org/10.1111/jgs.12607)

このゲームは医療機器ではありません。認知症を予防したり治したりするとは言いません。
